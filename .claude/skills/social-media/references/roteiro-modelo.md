# Modelo de roteiro por post

Campos do `posts.json` (um objeto por post):

```json
{
  "cliente": "Nome",
  "periodo": "Novembro/2026",
  "estrategia": {"objetivo": "", "publico": "", "tom": "", "pilares": ["", ""]},
  "posts": [
    {
      "data": "2026-11-03",
      "plataforma": "Instagram",
      "formato": "Reels | Carrossel | Estático | Stories",
      "pilar": "",
      "tema": "",
      "objetivo": "",
      "gancho": "primeiros 3s / primeiro slide",
      "roteiro": [
        {"cena": "1", "tempo": "0-3s", "visual": "", "fala_texto": ""}
      ],
      "legenda": "",
      "hashtags": ["#"],
      "cta": "",
      "direcao_arte": "cores, fontes, estilo, referências",
      "audio": "trilha ou fala",
      "link_canva": "",
      "observacoes": ""
    }
  ]
}
```

Reels: 15–45s, gancho em 3s, uma ideia por vídeo, legenda na tela.
Carrossel: 6–10 slides, slide 1 = promessa, último = CTA.
