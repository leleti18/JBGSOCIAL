# Modelo: análise de perfil

1. **Visão geral** — plataforma, @, seguidores, frequência, formatos dominantes
2. **Bio e identidade** — clareza da proposta, CTA, link, destaques, consistência visual
3. **Conteúdo** — pilares percebidos, tom de voz, qualidade de gancho/legenda
4. **Desempenho** — top 3 e bottom 3 posts (engajamento, alcance, salvamentos), o que explica
5. **Concorrentes** — tabela: perfil, frequência, formato forte, diferencial, lacuna
6. **Diagnóstico** — pontos fortes / fracos / oportunidades / riscos
7. **3 prioridades** — ações objetivas para os próximos 30 dias

Dados que não puderem ser verificados: marcar "a confirmar".
